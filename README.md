\# SearchEngine



Консольная поисковая система на C++20 для индексации текстовых документов и поиска по ним с использованием PostgreSQL.



\## Возможности



\- Рекурсивный поиск файлов с заданными расширениями.

\- Подсчёт частоты слов в документах.

\- Параллельная обработка файлов с использованием пула потоков.

\- Хранение индекса в PostgreSQL.

\- Обновление индекса документа при повторной обработке.

\- Поиск документов по нескольким словам.

\- Сортировка результатов по релевантности.

\- Модульные тесты основных компонентов.



\## Технологии



\- C++20

\- CMake

\- PostgreSQL

\- libpqxx

\- Boost.Locale

\- Catch2

\- vcpkg



\## Структура проекта



\- `src/IndexerMain.cpp` — точка входа индексатора.

\- `src/SearcherMain.cpp` — точка входа поисковой программы.

\- `src/config/Config.h` — чтение конфигурации.

\- `src/indexer/` — поиск файлов, обработка текста, сохранение индекса и пул потоков.

\- `src/searcher/` — обработка поисковых запросов и поиск документов.

\- `tests/` — модульные тесты.

\- `config/config.example.ini` — пример конфигурации.

\- `documents/` — демонстрационные документы.



\## Требования



\- Windows.

\- Visual Studio с поддержкой C++.

\- CMake.

\- vcpkg.

\- PostgreSQL.



Зависимости C++ устанавливаются через vcpkg на основе `vcpkg.json`.



\## Настройка



1\. Создайте базу данных PostgreSQL с именем `search\_engine`.

2\. Скопируйте `config/config.example.ini` в `config/config.ini`.

3\. Укажите в `config/config.ini` параметры подключения к PostgreSQL.

4\. В `search.root\_directory` укажите директорию с текстовыми документами.

5\. В `search.extensions` задайте расширения файлов для индексации.



Файл `config/config.ini` предназначен для локальных настроек и не должен попадать в Git, поскольку содержит пароль базы данных.



\## Сборка



Выполните команды в PowerShell из корневой директории проекта.



Настройка CMake:



```powershell

cmake -S . -B build -DCMAKE\_TOOLCHAIN\_FILE="$env:USERPROFILE\\vcpkg\\scripts\\buildsystems\\vcpkg.cmake"

```



Сборка:



```powershell

cmake --build build --config Debug

```



\## Запуск



Сначала запустите индексатор:



```powershell

.\\build\\Debug\\Indexer.exe

```



Затем запустите поиск:



```powershell

.\\build\\Debug\\Searcher.exe

```



Для завершения работы поисковой программы введите `exit`.



\## Правила поиска



\- Длина слова — от 3 до 32 символов.

\- Запрос может содержать не более 4 уникальных слов.

\- Документ должен содержать все уникальные слова запроса.

\- Релевантность рассчитывается как сумма частот искомых слов в документе.

\- Результаты сортируются по убыванию релевантности, затем по имени файла.

\- Для каждого результата выводятся имя файла, путь и релевантность.



\## Тестирование



Для запуска тестов выполните:



```powershell

ctest --test-dir build -C Debug --output-on-failure

```
