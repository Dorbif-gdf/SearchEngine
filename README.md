# SearchEngine

Консольная поисковая система на C++20 для индексации текстовых документов и поиска по ним с использованием PostgreSQL.

## Возможности

- Рекурсивный поиск файлов с заданными расширениями.
- Подсчёт частоты слов в документах.
- Параллельная обработка файлов с использованием пула потоков.
- Хранение поискового индекса в PostgreSQL.
- Обновление индекса документа при повторной индексации.
- Поиск документов по нескольким словам.
- Сортировка результатов по релевантности.
- Модульные тесты основных компонентов.

## Используемые технологии

- C++20
- CMake
- PostgreSQL
- libpqxx
- Boost.Locale

- vcpkg

## Настройка

1. Установите PostgreSQL и убедитесь, что сервер запущен.
2. Создайте базу данных с именем `search_engine`.
3. Скопируйте пример конфигурации:

   ```powershell
   Copy-Item config/config.example.ini config/config.ini
   ```

4. Откройте `config/config.ini` и укажите параметры подключения к PostgreSQL, включая пароль пользователя базы данных.
5. В параметре `root_directory` укажите путь к каталогу с документами для индексации.
6. В параметре `extensions` укажите расширения файлов через запятую, например `txt,md,ini,csv`.

Пример конфигурации находится в `config/config.example.ini`. Не добавляйте `config/config.ini` в Git: этот файл предназначен для локальных настроек и может содержать пароль.

При запуске индексатор автоматически создаёт необходимые таблицы, если они ещё не существуют.

## Сборка

Откройте PowerShell в корневой директории проекта.

Укажите путь к файлу `vcpkg.cmake` в своей установке vcpkg. Например, если vcpkg находится в `%USERPROFILE%\vcpkg`, выполните:

```powershell
cmake -S . -B build -DCMAKE_TOOLCHAIN_FILE="$env:USERPROFILE\vcpkg\scripts\buildsystems\vcpkg.cmake"
```

Если vcpkg установлен в другом каталоге, замените путь к `vcpkg.cmake` на фактический путь в вашей системе.

Соберите проект:

```powershell
cmake --build build --config Debug
```

## Запуск

Запускайте команды из корневой директории проекта после успешной сборки.

Сначала выполните индексатор:

```powershell
.\build\Debug\Indexer.exe
```

Он просканирует настроенный каталог, обработает подходящие файлы и сохранит индекс в PostgreSQL. При повторном запуске данные существующих документов по их полному пути обновляются.

Затем запустите поисковую программу:

```powershell
.\build\Debug\Searcher.exe
```

Введите поисковый запрос в консоль. Для завершения работы введите `exit`.

## Правила поиска

- Слова длиной менее 3 или более 32 символов не учитываются.
- Запрос может содержать не более 4 уникальных слов.
- Документ должен содержать все уникальные слова запроса, чтобы попасть в результаты.
- Релевантность рассчитывается как сумма частот искомых слов в документе.
- Результаты сортируются по убыванию релевантности, затем по имени файла.
- Выводятся имя файла, полный путь и значение релевантности.

## Тестирование

После сборки выполните из корневой директории проекта:

```powershell
ctest --test-dir build -C Debug --output-on-failure
```

Команда запускает зарегистрированные в CTest тесты проекта и выводит подробную информацию о результатах.
